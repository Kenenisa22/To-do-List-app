## 🚀 Features

- ✅ **Add Tasks** - Create new tasks with a single click or Enter key
- ✏️ **Edit Tasks** - Update existing task content
- ❌ **Delete Tasks** - Remove individual tasks
- ✅ **Mark as Complete** - Toggle task completion status
- 🔍 **Search Tasks** - Filter tasks by keyword (coming soon)
- 📂 **Filter Tasks** - View All, Active, or Completed tasks
- 💾 **Local Storage** - Tasks persist after browser refresh
- 📱 **Mobile Responsive** - Works on all screen sizes
- 🎨 **Glass-morphism UI** - Modern, sleek design with blur effects

## 🛠️ Technologies Used

- **HTML5** - Semantic markup
- **CSS3** - Flexbox, Grid, Animations, Backdrop-filter
- **JavaScript ES6** - DOM manipulation, Local Storage API
- **Font Awesome** - Icons for better UX
